# Simulasicat - FAST MVP (skeleton)

Quick start:

1. Install Node.js (v18+ or v20).
2. In project folder, run:
   ```
   npm install
   npm run dev
   ```
3. Open http://localhost:5173

Files included:
- src/ (React app skeleton)
- public/
- package.json (scripts)

Next steps:
- Replace Firebase config in src/services/firebase.js
- Implement logic in pages and services (placeholders provided)
